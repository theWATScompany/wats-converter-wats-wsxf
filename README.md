# WSXF Converter

**Format:** WATS Standard XML Format (WSXF)  
**Assembly:** `Virinco.WATS.Converter.WATS.WSXF`  
**Distribution:** Bundled with WATS Client — no separate installation required

## Description

Converts WATS Standard XML Format (WSXF) files to WATS UUT and repair reports.
WSXF is the native XML serialisation format produced by WATS Client and the WATS export API.
This converter allows you to re-ingest WSXF exports into any WATS server.

> **Note:** This converter ships as part of the WATS Client installation. It does not require
> a separate download or deployment.

## Format specification

See [WATS Standard XML Format (WSXF)](https://support.wats.com/hc/en-us/articles/207424643-Wats-Standard-Xml-Format-WSXF)
for the full format reference on the WATS support portal.
